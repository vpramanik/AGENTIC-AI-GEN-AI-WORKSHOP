1. Create virtual environment
--> python3 -m venv .venv

2. Activate virtual environment (command can change as per your Operating System slightly)
--> source ./.venv/bin/activate

3. Install dependencies
--> pip install -r requirements.txt

5. Run required files one by one
--> python3 1_tokenizer.py
--> python3 2_vocabulary.py
--> ...
